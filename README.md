## Design Highlights

- 🎨 Warm dark background (`#1a1917`) with Warm Parchment (`#faf9f6`) text
- ✍️ Mixed serif/sans typography — DM Serif Display for display headings, Crimson Pro for body, Inter for UI
- 🌌 Animated canvas particle mesh background (FEA mesh aesthetic)
- 🔮 Floating physics equations as ambient decorations (Navier-Stokes, Matern kernel, Hooke's Law)
- 📐 Scrolling equation marquee strip between sections
- ✨ Scroll-reveal animations, animated skill bars, warm orb glows
